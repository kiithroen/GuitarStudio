# Guitar Studio

클래식 기타 초보자가 내장곡이나 Google Sheets 악보를 연습하고, 메모리에서만 유지되는 텍스트 악보 초안을 만들거나 편집하며, 교본 이미지·PDF를 보며 연습할 수 있는 정적 웹 앱이야. 기존 TAB 악보와 박자 카드, 기타 지판 미리듣기, KS/classic 합성기, 메트로놈, 이미지 악보와 코드·가이드음·메모 편집을 제공해.

## 실행

Python이 설치돼 있으면 프로젝트 루트에서 정적 서버를 실행해.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8765/>를 열면 돼. 별도 백엔드, 빌드, npm 설치는 필요하지 않아. `file://`로 직접 열면 `songs.json`을 가져오지 못할 수 있어 정적 HTTP 실행을 권장해.

이미지·PDF 악보와 앱 설정은 브라우저 저장소에 저장돼. 저장 데이터는 origin(프로토콜·호스트·포트)과 브라우저에 연결되므로 주소나 브라우저를 바꾸면 자동으로 공유되지 않아. 이동하기 전 `백업·복원`에서 JSON 백업을 받아 둬.

## 초보 연습에 맞춘 기능

기본 화면은 내장곡과 Google Sheets에서 읽어 온 악보를 박자 카드와 TAB으로 보여 줘. 정지 상태에서 칸을 누르면 해당 칸을 미리 들어볼 수 있고, 지판을 눌러도 음을 미리 들을 수 있어. 재생 위치, 메트로놈, 구간 반복과 자동 가속을 사용해 연습하고 지판과 코드 카드를 함께 볼 수 있어. 왼손 운지와 오른손 `:p`, `:i`, `:m`, `:a` 운지는 악보 원문에 적힌 경우에만 표시하고, 빠진 운지를 추정하지 않아. 오른손 운지 표시는 소리를 바꾸지 않아.

교본 사진이나 PDF는 이미지 악보로 열어 메트로놈과 마디 영역을 설정할 수 있어. 앱은 음표를 자동으로 읽지 않으므로 텍스트 악보 입력 범위를 벗어나는 표기는 이미지·PDF 모드로 연습해.

## 지원 범위

텍스트 악보는 일정한 칸 수의 마디, 쉼, 음의 유지, 동시 화음, 2·3·4분할을 지원해. 독립 성부별 음가, 부분 붙임줄, 슬러·꾸밈음, 못갖춘마디, 가변 박자, 반복기호 자동 전개, 변칙 조율은 텍스트 해석 범위에 포함하지 않아. 자세한 문법은 [악보 입력 형식](Docs/score-format.md)을 봐.
