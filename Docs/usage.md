# 사용 안내

앱은 텍스트 악보 연습과 사진/PDF 교본 보기 기능을 제공해. 입력 문법은 [악보 입력 형식](score-format.md)을 참고해.

## 곡을 연습하기

곡 선택 메뉴에서 내장곡이나 저장한 개인 악보를 선택해. 직접 입력하려면 `+ 직접 악보 입력`에서 제목, 마디 칸 수, BPM과 악보를 입력해. `타브`와 박자 카드 화면을 전환할 수 있어. 정지 상태에서 칸을 누르면 해당 칸을 미리 들어볼 수 있고, 그 위치부터 연습하려면 `연습 시작`을 눌러. 재생 중 칸을 눌러도 현재 재생 스케줄은 이동하지 않아.

`구간 반복 (마디)`에서 시작·끝 마디를 지정해 반복할 수 있어. `자동 가속`을 켜면 두 번 완주할 때마다 3 BPM씩 올라가. `기타 시뮬레이션`은 앱의 기타 소리를 켜고 끄며 메트로놈은 유지해. 마이크 판정과 지연 보정 옵션, `6현 튜너`도 있어.

## 사진이나 PDF로 연습하기

`+ 교본 사진/PDF 악보 올리기`로 파일을 열어 이미지 악보 위에 메트로놈과 마디 영역을 설정해. PDF는 최대 6쪽까지 처리하고 PDF.js를 CDN에서 동적으로 불러올 수 있어. 따라서 PDF 기능의 오프라인 사용은 보장되지 않아.

앱 자체 음표 OCR은 없어. `검은 세로 마디선 자동 감지`는 마디 경계 후보만 찾으며 음표나 코드를 판독하지 않아. 텍스트 변환이 필요하면 `제미니/안티그래비티 질문용 프롬프트 복사`로 프롬프트를 복사하고, 사진과 함께 외부 AI 서비스에 전달한 뒤 결과를 앱에 붙여 넣어. 앱이 외부 AI로 직접 전송하는 기능은 없어.

## Google Sheets 연동

시트는 아래 5열 형식이야.

| A | B | C | D | E |
|---|---|---|---|---|
| 제목 | 칸수 | BPM | 설명 | 악보 |

앱의 `현재 선택된 악보를 시트 한 줄(TSV)로 복사`를 누르고 Google Sheets의 빈 행 A열에 붙여 넣어. 불러올 때는 로그인 없이 읽을 수 있도록 공유된 시트 URL을 `구글 시트 연동`에 입력해. 연동은 시트 내용을 읽어 앱에 가져오는 방식이며 앱이 시트에 자동으로 기록하지 않아. 가사 JSON 문자열 안의 `/`와 마디 구분 `//`는 그대로 유지해. 임의의 셀 범위를 복사해 앱이 자동 TSV 가져오기를 수행하는 흐름은 지원하지 않아.

## 백업과 데이터 이동

`백업·복원`에서 JSON 파일로 개인 악보, 앱 설정, 연습 기록을 내보내고 복원할 수 있어. Google Sheets 원본과 연결 URL은 백업에 포함되지 않으므로 새 환경에서는 시트 연결을 별도로 설정해야 해. 백업 데이터에는 지연 보정 값이 포함되지만, 현재 가져오기는 이 값을 다시 적용하지 않아. 복원 후 지연 보정은 다시 설정해야 해.

개인 데이터는 브라우저 저장소에 있고 origin과 브라우저별로 분리돼. 다른 호스트·포트·브라우저로 옮기기 전 백업 파일을 준비해.
