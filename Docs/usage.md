# 사용 안내

앱은 내장곡과 Google Sheets에서 읽어 온 텍스트 악보, 앱을 닫으면 사라지는 임시 텍스트 악보, 사진/PDF 교본 보기 기능을 제공해. 텍스트 악보 문법은 [악보 문법](score-format.md)에 있어.

## 곡을 연습하기

악보 바로 위 툴바의 곡 선택에서 내장곡이나 Google Sheets에서 불러온 악보를 고르고(내장곡은 `Lv.1 입문`부터 `Lv.5 중상급`까지 레벨별로 묶여 있어), 옆의 `▶ 시작`/`⏹ 정지`(Space)로 연습을 시작하고 멈춰. `처음으로`(Home)는 긴 악보를 스크롤하던 중에도 커서와 스크롤을 첫 마디로 돌려. `타브`·`둘 다`(오선+타브)·`오선`·`카드`(박자 카드) 중에서 보기를 고를 수 있고(`T` 키로 차례로 바뀌어), 상단 헤더의 `도레미 표기 / CDE 표기`로 화면 전체의 음이름 표기를 바꿔(기본값 CDE). 헤더의 `단축키 안내`나 `?`를 누르면 키보드 단축키와 마우스 조작 안내를 볼 수 있어.

정지 상태에서 마디 바깥 부분을 누르면 시작 위치를 선택하고, Shift를 누른 채 누르면 반복 구간의 끝을 선택해. 음이나 TAB 칸을 누르면 미리 들어볼 수 있어. 그 위치부터 연습하려면 시작을 눌러. 재생 중 칸을 눌러도 현재 재생 스케줄은 이동하지 않아.

`구간 반복 (마디)`에서 시작·끝 마디를 지정해 반복할 수 있어. `자동 가속`을 켜면 두 번 완주할 때마다 3 BPM씩 올라가. 콘솔 1번째 템포 박스 헤더의 `기타 시뮬레이션` 토글 버튼(단축키: G)은 앱의 기타 연주 소리를 켜고 끄며 메트로놈은 유지해. `클릭 모드`에서 메트로놈 클릭을 고를 수 있어. `전부`는 시작 전 한 마디 카운트인과 재생 내내, `카운트인만`은 시작 전 한 마디만 클릭하고, `끄기`는 클릭 없이 카운트인도 건너뛰고 바로 시작해. `클릭음` 슬라이더는 클릭 볼륨이야. `출력 지연`에서 무선 이어폰이나 스피커의 출력 지연에 맞춰 화면 커서 오프셋을 조절할 수 있어.

악보에 적힌 음표 길이와 실제 소리의 자연스러운 여운은 다를 수 있어. 음가가 끝났다고 기타 소리가 바로 끊기는 건 아니고, 같은 현 재탄현이나 전체 쉼·정지·곡 교체·기타 시뮬레이션 끄기·곡 또는 반복 구간 끝에서 직접음이 정리돼.

## 임시 악보 만들기와 편집

화면 오른쪽 위의 `빈 악보 추가`를 누르면 제목, 마디 칸수, BPM을 입력하는 창이 열려. 새 악보는 모든 칸이 쉼인 한 마디로 시작해. 기본 제목은 `빈 악보 N`, 칸수는 4, BPM은 64야. 취소하면 악보가 추가되지 않아.

내장곡이나 시트 악보의 마디 메뉴에서 `편집`을 선택하면 원본의 복사본을 임시 초안으로 편집해. 원본은 바뀌지 않고, 다른 곡으로 갔다 돌아와도 이 탭을 새로고침하기 전까지 초안이 남아 있어. 새 임시 악보와 편집 초안은 새로고침하면 모두 사라져.

마디 메뉴에서 한 마디를 고치거나, 뒤에 마디를 추가하거나, 삭제할 수 있어. 한 번에 하나의 마디만 편집하며, 편집 내용을 적용하기 전에 악보 전체를 검사해. 오류가 있으면 수정 내용을 적용하지 않고 원문을 보존해. 고치기를 취소하면 편집 전 내용으로 돌아가. 임시 초안에는 한 단계 실행 취소와 원본으로 되돌리기가 있어. 마지막 한 마디는 삭제할 수 없어.

마디 편집이 열려 있는 동안에는 다른 편집, 곡 전환, 복사, 재생을 시작할 수 없어. 안내에 따라 현재 편집을 적용하거나 취소한 뒤 진행해. 편집을 적용하는 동안 BPM, 현재 커서, 반복 구간은 이어서 유지돼.

## 타브로 악보 입력하기

곡 선택 바의 `악보 입력`을 누르면 악보 입력 화면으로 가. 마디마다 6줄 타브가 있고, 타브의 자리를 누른 뒤 화면 아래 입력판의 지판에서 프렛을 누르면(개방현은 0) 그 자리에 음이 들어가. 같은 칸에 여러 줄을 넣으면 화음이야. 숫자키로 프렛을, 방향키로 자리를 옮길 수도 있어. 입력판의 `입력하면 다음 칸으로`를 켜면 선율은 지판만 눌러 한 음씩 이어서 넣어.

빈 칸은 앞 음을 이어 끌고, 쉬는 칸은 `쉼표`(R)로 정해. 칸을 2·3·4로 나누면 8분음표·셋잇단·16분음표를 넣을 수 있어. 음을 고른 상태에서 입력판 아래 줄로 왼손·오른손 운지, 아포얀도·티란도, 확인 표시 `?`를 붙여. 마디 번호를 누르면 마디를 골라 복사·붙여넣기·복제·삭제할 수 있고, 반복은 `복제`로 펼쳐 적어. 카포는 설명에 `Capo 2`처럼 적어.

마디마다 타브 위에 넣은 음이 기타 오선보로 같이 그려져서 책과 바로 대조할 수 있어. 곡 정보의 `조표`를 책과 같게 고르면 조표에 든 음에는 임시표가 안 붙어 책과 모양이 같아져. 오선은 문법 그대로라 음 길이는 다음 음이 나올 때까지로 그려(책에서 길게 끄는 베이스가 짧게 보일 수 있어). 입력판의 `오선 보기`로 끄고 켜. 마디 카드 아래 결과 영역에 텍스트 악보가 바로 나와. `시트용 TSV 복사`로 Google Sheets에 넣거나, `연습 화면에서 열기`로 연습 화면의 임시 악보로 열어 들어 봐. 작업 중인 악보 하나는 이 기기에 자동 저장돼서 새로고침해도 남아. 다른 곡을 시작하기 전에는 TSV로 복사해 시트에 보관해. 연습 화면의 `악보 복사`로 복사한 TSV를 `불러오기`에 붙여 넣으면 내장곡이나 시트 곡도 타브로 고칠 수 있어. 자세한 조작과 단축키는 [악보 입력](tab-input.md)에 있어.

## 사진이나 PDF로 연습하기

`+ 교본 사진/PDF 악보 올리기`로 파일을 열어 이미지 악보 위에 메트로놈과 마디 영역을 설정해. 업로드한 이미지·PDF 악보는 페이지, 영역, 마디 경계와 함께 편집할 수 있고, 마디마다 코드·가이드음·메모를 기록할 수 있어. PDF는 최대 6쪽까지 처리하고 PDF.js를 CDN에서 동적으로 불러올 수 있어. 따라서 PDF 기능의 오프라인 사용은 보장되지 않아.

`검은 세로 마디선 자동 감지`는 마디 경계 후보만 찾으며 음표나 코드를 판독하지 않아. 앱은 이미지에서 텍스트 악보를 자동 변환하지 않아. 지원되지 않는 고급 표기는 이미지·PDF 악보로 연습해.

곡 선택 바의 `사진 변환 프롬프트 복사`를 누르면 악보 이미지를 이 앱의 텍스트 악보로 바꾸는 AI용 프롬프트가 클립보드에 복사돼. 이미지를 첨부할 수 있는 AI 채팅에 이미지와 함께 붙여 넣으면 한 줄에 한 마디인 악보, Google Sheets용 TSV 한 행, 바꾸거나 확인 표시를 붙인 마디 요약을 받아. TSV 행은 Google Sheets 빈 행 A열에 붙여 넣고 `구글 시트 연동`으로 불러와. AI 결과는 틀릴 수 있으니 원본과 대조해. 확실하지 않은 음에는 확인 표시 `?`가 붙어 오고, 앱은 그 칸을 경고색으로 칠하고 툴바에 개수를 보여 줘. 확인한 뒤 마디 편집에서 `?`를 지워. 꾸밈음이나 여러 성부처럼 문법에 맞지 않는 표기는 AI가 가볍게 편곡해 옮기고 마디 메모에 적어 와. 저장소를 열어 둔 코딩 AI를 쓸 때는 옆의 `프로젝트 AI용 프롬프트 복사`를 쓰면, AI가 문법 문서를 직접 읽고 `tools/check-score.js`로 검사한 TSV를 `Temp/scores/`에 남겨.

## Google Sheets 연동

시트는 한 행이 곡 하나인 5열(제목, 칸 수, BPM, 설명, 악보) 형식이야. 열마다 받는 값과 옛 형식, 카포 표기는 [악보 문법](score-format.md#시트-한-행과-카포)에 있어.

로그인 없이 읽을 수 있도록 공유된 시트 URL을 `구글 시트 연동`에 입력하면 불러와. 연동은 시트 내용을 읽기만 하고 앱이 시트에 직접 기록하지 않아. 앱 안의 임시 편집은 현재 탭의 초안에만 적용되고 시트 원본으로 되돌아가지 않아.

`콤팩트 뷰` 옆의 `악보 복사`는 현재 악보를 이 5열 TSV 한 줄로 복사해. Google Sheets의 빈 행 A열에 붙여 넣으면 돼. 원문 운지, 주법, 메모, 코드와 카포 정보도 보존돼. 마디 메모·가사 JSON 문자열 안의 `/`와 마디 구분 `//`는 그대로 유지해. 임의의 셀 범위를 복사해 앱이 자동 TSV 가져오기를 수행하는 흐름은 지원하지 않아.

앱을 열 때 저장된 시트를 자동으로 다시 불러와. 틀린 행이 하나라도 있으면 시트 곡을 하나도 불러오지 않고, 곡 선택 바 아래에 몇 행 몇 마디가 왜 틀렸는지 보여 줘. 시트를 고친 뒤 `구글 시트 연동`에서 다시 불러와.

## 백업과 데이터 이동

`백업·복원`은 이미지·PDF 악보와 앱 설정을 JSON 파일로 내보내고 복원해. 임시 텍스트 악보와 초안은 백업하지 않아. 수동 출력 지연값은 앱 설정으로 함께 백업되고 복원돼. Google Sheets 원본과 연결 URL은 백업에 포함되지 않으므로 새 환경에서는 시트 연결을 별도로 설정해야 해.

이미지·PDF 악보는 IndexedDB에, 앱 설정과 곡별 최근 연습 BPM·구간 이어가기 상태는 localStorage에 저장돼. 개인 데이터는 origin과 브라우저별로 분리되므로 다른 호스트·포트·브라우저로 옮기기 전 백업 파일을 준비해.
