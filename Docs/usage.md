# 사용 안내

앱은 내장곡과 Google Sheets에서 읽어 온 텍스트 악보, 앱을 닫으면 사라지는 임시 텍스트 악보, 사진/PDF 교본 보기 기능을 제공해. 악보 문법은 [악보 입력 형식](score-format.md)을 참고해.

## 곡을 연습하기

일반 뷰와 콤팩트 뷰 모두 악보 바로 위 툴바의 곡 선택 드롭다운에서 내장곡이나 Google Sheets에서 불러온 악보를 선택할 수 있고, 바로 옆 시작 버튼(`▶ 시작`/`⏹ 정지`, 단축키: Space)으로 어디서든 즉시 연습을 시작하고 멈출 수 있어. 기존 악보를 임시로 고쳐 연습하거나 새 임시 악보를 만들 수 있어. 임시 악보는 앱 안에서만 유지되고 새로고침하면 사라져. 내장곡과 Google Sheets 원본은 바뀌지 않아. 악보 복사 버튼으로 현재 악보를 Google Sheets용 TSV 한 줄로 복사할 수 있어. `타브`와 박자 카드 화면을 전환할 수 있어. 카드 뷰에서는 오른손 운지가 불필요한 접두사 없이 간결하게(`p + a`, `i / m` 등) 표시돼. 상단 헤더의 `도레미 표기 / CDE 표기` 버튼으로 화면 전체의 음이름·계이름 표기법을 원클릭으로 전환할 수 있어(기본값은 CDE 표기법). 정지 상태에서 마디 바깥 부분을 누르면 시작 위치를 선택하고, Shift를 누른 채 누르면 반복 구간의 끝을 선택해. 음이나 TAB 칸을 누르면 기존처럼 미리 들어볼 수 있어. 악보의 그 위치부터 연습하려면 시작 버튼(`▶ 시작` 또는 단축키: Space)을 눌러. 재생 중 칸을 눌러도 현재 재생 스케줄은 이동하지 않아.

`구간 반복 (마디)`에서 시작·끝 마디를 지정해 반복할 수 있어. `자동 가속`을 켜면 두 번 완주할 때마다 3 BPM씩 올라가. 콘솔 1번째 템포 박스 헤더의 `기타 시뮬레이션` 토글 버튼(단축키: G)은 앱의 기타 연주 소리를 켜고 끄며 메트로놈은 유지해. `클릭 모드`에서 메트로놈 클릭을 고를 수 있어. `전부`는 시작 전 한 마디 카운트인과 재생 내내, `카운트인만`은 시작 전 한 마디만 클릭하고, `끄기`는 클릭 없이 카운트인도 건너뛰고 바로 시작해. `클릭음` 슬라이더는 클릭 볼륨이야. `출력 지연`에서 무선 이어폰이나 스피커의 출력 지연에 맞춰 화면 커서 오프셋을 조절할 수 있어.

악보에 적힌 음표 길이와 실제 소리의 자연스러운 여운은 다를 수 있어. 음가가 끝났다고 기타 소리가 바로 끊기는 건 아니고, 같은 현 재탄현이나 전체 쉼·정지·곡 교체·기타 시뮬레이션 끄기·곡 또는 반복 구간 끝에서 직접음이 정리돼.

## 임시 악보 만들기와 편집

화면 오른쪽 위의 `빈 악보 추가`를 누르면 제목, 마디 칸수, BPM을 입력하는 창이 열려. 새 악보는 모든 칸이 쉼인 한 마디로 시작해. 기본 제목은 `빈 악보 N`, 칸수는 4, BPM은 64야. 취소하면 악보가 추가되지 않아.

내장곡이나 시트 악보의 마디 메뉴에서 `편집`을 선택하면 원본의 복사본을 임시 초안으로 편집해. 원본은 바뀌지 않고, 다른 곡으로 갔다 돌아와도 이 탭을 새로고침하기 전까지 초안이 남아 있어. 새 임시 악보와 편집 초안은 새로고침하면 모두 사라져.

마디 메뉴에서 한 마디를 고치거나, 뒤에 마디를 추가하거나, 삭제할 수 있어. 한 번에 하나의 마디만 편집하며, 편집 내용을 적용하기 전에 악보 전체를 검사해. 오류가 있으면 수정 내용을 적용하지 않고 원문을 보존해. 고치기를 취소하면 편집 전 내용으로 돌아가. 임시 초안에는 한 단계 실행 취소와 원본으로 되돌리기가 있어. 마지막 한 마디는 삭제할 수 없어.

마디 편집이 열려 있는 동안에는 다른 편집, 곡 전환, 복사, 재생을 시작할 수 없어. 안내에 따라 현재 편집을 적용하거나 취소한 뒤 진행해. 편집을 적용하는 동안 BPM, 현재 커서, 반복 구간은 이어서 유지돼.

악보 복사 버튼은 `콤팩트 뷰` 옆에 있어. 제목, 칸수, BPM, 설명, 악보의 다섯 열을 TSV로 복사해 Google Sheets의 빈 행 A열에 붙여 넣을 수 있어. 원문 운지, 주법, 메모, 코드와 카포 정보도 보존돼. 앱은 Google Sheets에 직접 기록하지 않아.

## 사진이나 PDF로 연습하기

`+ 교본 사진/PDF 악보 올리기`로 파일을 열어 이미지 악보 위에 메트로놈과 마디 영역을 설정해. 업로드한 이미지·PDF 악보는 페이지, 영역, 마디 경계와 함께 편집할 수 있고, 마디마다 코드·가이드음·메모를 기록할 수 있어. PDF는 최대 6쪽까지 처리하고 PDF.js를 CDN에서 동적으로 불러올 수 있어. 따라서 PDF 기능의 오프라인 사용은 보장되지 않아.

`검은 세로 마디선 자동 감지`는 마디 경계 후보만 찾으며 음표나 코드를 판독하지 않아. 앱은 이미지에서 텍스트 악보를 자동 변환하지 않아. 지원되지 않는 고급 표기는 이미지·PDF 악보로 연습해.

## Google Sheets 연동

시트는 아래 5열 형식이야.

| A | B | C | D | E |
|---|---|---|---|---|
| 제목 | 칸수 | BPM | 설명 | 악보 |

외부에서 작성한 악보나 앱에서 복사한 TSV를 이 형식에 맞춰 Google Sheets에 넣어. 앱에서 `악보 복사`를 누르면 선택한 악보를 빈 행 A열에 붙여 넣을 수 있어. 불러올 때는 로그인 없이 읽을 수 있도록 공유된 시트 URL을 `구글 시트 연동`에 입력해. 연동은 시트 내용을 읽는 방식이며 앱이 시트에 직접 기록하지 않아. 앱 안의 임시 편집은 현재 탭의 초안에만 적용되고 시트 원본으로 되돌아가지 않아. 마디 메모·가사 JSON 문자열 안의 `/`와 마디 구분 `//`는 그대로 유지해. 임의의 셀 범위를 복사해 앱이 자동 TSV 가져오기를 수행하는 흐름은 지원하지 않아.

## 백업과 데이터 이동

`백업·복원`은 이미지·PDF 악보와 앱 설정을 JSON 파일로 내보내고 복원해. 임시 텍스트 악보와 초안은 백업하지 않아. 수동 출력 지연값은 앱 설정으로 함께 백업되고 복원돼. Google Sheets 원본과 연결 URL은 백업에 포함되지 않으므로 새 환경에서는 시트 연결을 별도로 설정해야 해.

이미지·PDF 악보는 IndexedDB에, 앱 설정과 곡별 최근 연습 BPM·구간 이어가기 상태는 localStorage에 저장돼. 개인 데이터는 origin과 브라우저별로 분리되므로 다른 호스트·포트·브라우저로 옮기기 전 백업 파일을 준비해.
