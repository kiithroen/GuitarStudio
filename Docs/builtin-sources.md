# 내장곡의 선율 출처와 운지 제안

**출처 대조일: 2026-10-19.** 내장 악보는 기타 연습용 편집판이야. 출처에서 확인한 선율과 앱이 작성한 현·왼손·오른손 운지 제안을 구분해 기록해. 앱의 운지 표기를 출처 악보의 운지로 설명하지 않아.

## 레벨

곡 선택 목록은 `songs.json`의 `level`로 내장곡을 묶어 보여 줘. 레벨 이름은 `src/app.js`의 `BUILTIN_LEVEL_NAMES` 한 곳에만 있어.

| 레벨 | 이름 | 기준 |
|---|---|---|
| 1 | 입문 | 1포지션, 1~3번 줄 단선율, 4분·2분음표 |
| 2 | 초급 | 1포지션 전체 줄, 8분·점음표, 간단한 저음 |
| 3 | 초중급 | 선율과 저음 두 성부, 3/4·6/8, 쉬운 아르페지오 |
| 4 | 중급 | 아르페지오 연습곡, 셋잇단, 5프렛 안쪽 이동 |
| 5 | 중상급 | 명곡, 바레, 높은 포지션 |

기준은 곡을 넣을 때 고르는 길잡이야. 곡마다 기준을 모두 맞춘다는 뜻은 아니야.

2026-10-19 결정: 레벨이 제목 앞 `[Lv.N 이름]` 글자에만 있고 Lv.3에 초중급과 중급이 섞여 있어서, `level` 필드로 옮기고 5단계로 정리했어. 제목과 배지의 레벨 글자는 지웠어. 로망스 선율·베이스판은 Lv.4, 셋잇단 아르페지오판은 Lv.5야. 곡 `id`의 `lv` 숫자는 예전 레벨이 남은 것이고 바꾸지 않아. 사용자 브라우저에 곡별 BPM·구간 상태가 `id`로 저장되기 때문이야.

2026-10-19 결정: 학교종을 뺐어. 김메리(1904~2005) 작곡이라 저작권이 2075년까지 남아 있고, 원악보와 대조도 하지 못했어.

## 원본 MIDI에서 옮긴 곡 (2026-10-19)

메리의 어린 양과 Mutopia 연습곡 8곡은 원본 MIDI(Mutopia는 같은 `.ly`에서 만든 MIDI)를 읽어 칸 격자에 맞춰 옮겼어. 같은 시점에 시작하는 음은 `+`로 묶고, 새로 시작하는 음이 없는 칸은 앞 음이 울리고 있으면 `-`, 아니면 `r`로 적었어. 그래서 성부마다 다른 길이는 같은 칸 길이로 합쳐져. 원본에 없는 코드는 `[-]`, 운지·주법은 붙이지 않았어(기본 줄이 겹치는 화음만 `@줄`을 붙였어). 반복과 D.C.는 펼치지 않았어. `test/test-builtins.js`는 이 곡들을 앱 운지 제안 검사에서 빼고, 대신 검증 오류·경고가 0이고 확인 표시가 없는지 봐.

변환 도구는 `tools/midi-to-score.js`, 곡별 설정은 `tools/builtin-recipes.json`(원본 MIDI URL, 칸 수·transpose 같은 옵션, 아델리타 꾸밈음 편집, 카룰리 안단티노 마지막 칸 수정, `@줄` 충돌 해소 여부)이야. 원본 MIDI는 저장소에 넣지 않아. 레시피의 URL에서 받은 파일을 한 폴더에 두고 `node tools/rebuild-builtins.js <폴더>`를 돌리면 곡마다 `songs.json`과 일치하는지 알려 줘. BPM은 레시피가 아니라 `songs.json`이 기준이야.

라이선스: 작곡가는 모두 저작권이 끝났어. 판본 라이선스는 곡마다 달라. 소르 Op.60 No.1·아델리타(CC BY-SA 2.5), 소르 Op.35 No.22(CC BY-SA 3.0)에서 옮긴 이 앱의 악보 데이터는 각 판본과 같은 CC BY-SA로 배포해. 카룰리 2곡(CC BY 4.0)과 줄리아니(CC BY 3.0)는 위 표의 출처 표기로 저작자 표시를 해. 카르카시 2곡은 판본도 퍼블릭 도메인이야. 메리의 어린 양은 Lowell Mason(1792~1872)의 선율이고, fluteTunes 페이지에는 사이트 저작권 표기만 있고 악보 라이선스 표기는 없어. 다른 fluteTunes 출처 곡처럼 선율만 옮겼고 발행자의 편곡 저작권을 퍼블릭 도메인으로 주장하지 않아. 2026-10-19 결정: 메리의 판본은 붓점 리듬(점8분+16분)이 들어 있어 Lv.1 기준(4분·2분음표)보다 어려워서 Lv.2 맨 앞에 뒀어.
