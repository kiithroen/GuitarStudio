# 악보 입력 형식

Google Sheets에서 불러오거나 앱의 임시 악보 초안에서 편집하는 텍스트 악보의 문법이야. 앱 안에서 바꾼 내용은 현재 탭에만 남고 원본이나 Google Sheets에 기록되지 않아. 사용 흐름은 [사용 안내](usage.md), 재생 내부 계약은 [리듬·오디오 계약](beginner-rhythm.md)을 봐.

## 마디와 칸

마디는 `//` 또는 줄바꿈으로 나눠. 공백은 칸을 구분하고, 한 칸 안의 균등 분할은 붙여 쓴 `/`로 적어. 분할 수는 2·3·4만 지원해.

```text
[C] C4 D4 E4 F4 | "2번 줄에서 1번 줄로 이동"
[-] G4/-/A4 B4 C5 D5 | ""
```

예시는 4칸 마디 두 개야. `|` 뒤에는 마디 메모(운지법, 현·프렛, 포지션 이동, 연습 주의사항)를 JSON 문자열로 기록해. 가사도 같은 칸에 적을 수 있고, 필요 없으면 빈 문자열로 둬. 코드 머리표 `[C]`처럼 코드를 명시할 수 있고, `[-]`는 코드 없음, `[?]`는 코드 추론을 표시해. 머리표를 생략하면 코드 추론 대상이 될 수 있어. 원문에 코드가 없음을 보존하려면 `[-]`를 써.

## 음, 쉼, 유지, 화음

- `C4` 같은 음이름은 조표나 앞선 임시표와 무관하게 토큰 자체를 실음 MIDI로 계산해. 각 음의 실제 높이를 `C#4`, `Bb3`처럼 적고 옥타브를 명시하는 게 좋아. `@`를 생략하면 기본 현·프렛 위치를 배치하고, 필요한 경우 `@1`~`@6`으로 현을 지정해. 표시되는 왼손 운지 번호는 원문에 직접 적은 숫자뿐이야.
- `r` 또는 `R`은 전체 쉼이며 그 시점에 모든 기타 직접음을 정리해. 콘서트홀 잔향은 남을 수 있어.
- `-`는 바로 앞 음이나 화음 전체를 다시 치지 않고 유지해. 마디를 넘어갈 수 있어.
- `+`는 구성음을 동시에 치는 화음이야. 예: `C3@5+E3@4+G3@3`.
- 음표 앞 `0`~`4`는 명시 왼손 운지야. `@1`~`@6`은 현 번호야. 예를 들어 `1C4@2`는 왼손 1번으로 2번 줄에서 치고, `C4@2`는 해당 현만 지정해.
- TAB에는 `1C4@2`가 `1(1)`(1번 프렛, 왼손 1번), `C4@2`가 `1`(1번 프렛)로 표시돼.
- 오른손 손가락은 음표 뒤 소문자 접미사 `:p`(엄지), `:i`(검지), `:m`(중지), `:a`(약지)로 선택해 적어. 예: `C4:i`, `1C4@2:i`, `!1C4@2:i`, `~E4:a`, `D4(4):i`, `도4:m`. 생략할 수 있고, 앱은 원문에 없는 운지를 추정하거나 옆 음에서 전파하지 않아. 화면 표시 메타데이터라서 적거나 바꿔도 음색, gain, 타이밍, 피치와 재생 동작은 바뀌지 않아.
- 화음은 구성음마다 접미사를 붙여. 예: `C3@5:p+1C4@2:i`. 음을 입력한 순서와 관계없이 각 운지는 그 구성음에 붙어 있어. 아포얀도 `!`나 티란도 `~`를 표시할 때도 해당 주법을 쓸 구성음마다 따로 적고, 화음의 한 구성음에 적은 주법을 다른 구성음에 전파하지 않아.
- 분할음도 각 part에 따로 적을 수 있어. 예: `E4:i/F4:m/-`는 오른손 표시가 순서대로 `i / m / -`야.
- 아포얀도 표시는 `!`만 지원해. `>`와 `^`는 더 이상 지원하지 않으며 `!`로 바꿔 적어. `~`는 티란도 표시야. 이 주법 표시는 오른손 손가락과 별개고 재생에 적용되지만, 음이름 표시에는 기호나 주법 색을 붙이지 않아([화면과 조작](ui.md)).

### 확인 표시 `?` (2026-10-19)

칸이나 분할 조각, 화음 구성음 끝에 `?`를 하나 붙이면 확인이 필요하다는 표시야. 예: `E4?`, `1C4@2:i?`, `C3@5+E4@1?`, `E4?/F4`. 앱은 `?`를 뗀 음을 그대로 파싱·재생하고, 그 칸을 TAB과 박자 카드에서 경고색으로 칠하고, 악보 툴바에 `확인 N곳` 배지를 띄워. `r?`와 단독 `?`는 확인 표시가 붙은 쉼이야. `?`는 하나만 붙일 수 있고 `??`, `-?`는 오류야. 악보 복사(TSV)에도 `?`가 그대로 남아. 확인을 마치면 마디 편집에서 `?`를 지워.

코드 머리표의 `[?]`·`[C?]`는 이와 별개로 코드 추론 표시야.

2026-10-19 결정: AI로 사진을 변환할 때 읽지 못한 음을 오류로 막으면 시트 전체가 안 들어오고 사용자가 AI를 여러 번 다시 돌리게 돼. 불러오기는 통과시키고 위치만 눈에 띄게 해서 앱에서 직접 고치게 했어.

### 음가

음표마다 별도 길이를 적는 `*N` 접미사는 지원하지 않아. 길이는 칸, `/` 분할, `-` 유지로만 정해져. 화음 구성음에는 각 음의 현·운지·주법을 적을 수 있지만 개별 길이를 나누지는 못해. 악보 음가와 기타 소리의 자연 여운은 별개라 음가가 끝나도 소리가 이어질 수 있어. 소리가 정리되는 경계와 중간 시작 때 유지음 복원은 [리듬·오디오 계약](beginner-rhythm.md)에 있어.

`C4/-/-/D4`는 한 칸을 4분할해 C4를 3/4칸 유지하고 D4를 마지막 1/4칸에 쳐. `C4 - - - // [-] - r D4 r`는 각각 4칸인 두 마디 예시야. 첫 마디 마지막 음을 둘째 마디 첫 칸까지 유지하고, 그 다음 칸은 쉼이야. 쉼 뒤 유지 기호는 오류야.

## 박자와 BPM

화면에서 선택하는 마디 칸 수는 2, 3, 4, 6, 8, 9야. BPM은 분당 칸 수야. 6/8과 9/8은 한 칸이 8분음표고, 8칸은 4/4의 8분음표 단위야. 2·3·4칸은 한 칸이 4분음표야. 인쇄 악보의 템포 음표가 다르면 칸 단위 BPM으로 환산해.

예를 들어 4/4에서 4분음표=60이면 8분음표 칸 기준 120이야. 점4분음표=60이면 8분음표 칸 기준 180이야. 3/4 셋잇단은 3칸을 선택하고 각 칸을 `/`로 3분할해.

## 카포와 오류

제목이나 배지에 `Capo 2` 또는 `카포: 2`를 적으면 우선 적용돼. 없으면 저장된 카포 값을 사용해. 값은 0~12 범위고, 표시 프렛은 카포 기준 상대 위치를 유지하며 재생 실음에 오프셋을 한 번 적용해.

`.` 토큰, 고아 유지, 마디 칸 부족·초과, 알 수 없는 음, 불가능한 현 지정, 지원하지 않는 분할은 오류야. 오류가 있는 텍스트 악보는 불러오기·TSV 복사·재생이 차단돼. Google Sheets 원본에서 오류를 수정한 뒤 다시 불러와.

독립 성부별 레인과 쉼, 화음 구성음별 길이 지정, 화음 일부의 붙임줄, 슬러·꾸밈음, 못갖춘마디, 가변 박자, 반복기호 자동 전개, 변칙 조율은 텍스트 해석에서 지원하지 않아. 반복기호는 텍스트로 직접 펼쳐 적을 수 있고, 그 밖에는 이미지 악보 모드를 사용해.
